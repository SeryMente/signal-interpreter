# Signal Interpreter Protocol v1

## Endpoint

ws://127.0.0.1:8787/

## Event envelope

Every event is a JSON object with at least:

- type
- timestamp

Events generated by the bridge may also include sequence when they originate in the UIA loop.

## Bridge events

### bridge.status

Indicates transport startup.

Fields:

- type: bridge.status
- status: listening | transport_disabled
- protocol: signal-interpreter.v1
- transport: websocket
- url

### bridge.connected

Sent to a newly connected extension client.

### bridge.heartbeat

Sent every 15 seconds while the native transport is alive.

### bridge.error

Diagnostic bridge error.

## Caption events

### caption.status

Fields:

- status: found | not_found

### caption.delta

Raw append-style snapshot change. Diagnostic only.

### caption.revision

Raw replacement-style snapshot change. Diagnostic only.

### caption.segment

Stable reconciled CLIENTE text.

Fields:

- mode: final
- source: live-caption
- reason: stable | stable-before-revision | caption-cleared
- text
- snapshot

## Consumer rule

The extension should use caption.segment as the authoritative text stream for CLIENTE.

caption.delta and caption.revision are observability signals and must not be appended directly to the visible CLIENTE transcript.

## Channel separation

CLIENTE is the observed external signal.

YO is the interpreter's own production channel.

No event from the CLIENTE pipeline should be silently inserted into YO, and YO input should not be sent to the CLIENTE stream.
