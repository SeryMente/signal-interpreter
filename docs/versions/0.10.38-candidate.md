# Signal Interpreter 0.10.38 — candidata consolidada, NO liberada

## Contenido
- Base actual de main 0.10.37, conservando las correcciones de ciclo de vida del overlay y el instalador verificable ya integradas.
- Control de presencia con autorización efímera y sin rearme automático; incertidumbre o ausencia de señal bloquea el auto-answer.
- Segmentación conservadora de los subtítulos de Live Caption en tramos lingüísticos. Los tramos ambiguos quedan sin asignar; idioma no demuestra identidad de hablante.
- Sondeo horario de estadísticas que omite de forma controlada la ausencia de una pestaña autenticada de Cloud Interpreter, sin crear, navegar ni recargar pestañas.
- Inventario de payload que debe validar cada archivo individualmente en Windows PowerShell 5.1.

## Compatibilidad de controles
Se conserva la única definición existente del atajo global: `toggle-global-overlays`, `Ctrl+Shift+8`. No se introduce el atajo alterno `Ctrl+Shift+Y` ni una segunda orden para la misma acción.

## Alcance y seguridad
La fuente de transcripción sigue siendo exclusivamente el texto nativo de Live Caption. No se añade captura de micrófono, audio de pestaña, reproducción, Groq ni inferencia de identidad de hablante.

## Compuertas obligatorias antes de liberar
1. CI verde sobre el SHA exacto de la PR consolidada, incluido el inventario de integridad.
2. Windows PowerShell 5.1: instalación limpia, actualización sobre una instalación preparada, registro de Native Messaging y comprobación de hashes, sin scripts obsoletos ni registro parcial.
3. Windows/Chrome real: idle, bloqueo/desbloqueo, suspensión corta, errores y reinicio; comprobar que la llamada actual no se cuelga ni se interrumpe.
4. Live Caption nativo real: tramos en inglés/español, texto conservado sin pérdidas ni duplicación, tramos ambiguos no asignados y repetibilidad.
5. Confirmación del operador sobre la revisión instalada y un informe nuevo sin datos de conversación.

Las pruebas sintéticas de navegador no equivalen a aceptación Windows. Hasta completar estas compuertas, esta revisión es una candidata de integración, no un release ni una instrucción para sustituir una instalación activa.
