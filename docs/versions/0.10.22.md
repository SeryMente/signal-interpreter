# Signal Interpreter 0.10.22 — Transcripción bilingüe y normalización de idioma

## Antes
La transcripción durable enviaba a Groq el parámetro de idioma español incluso cuando el audio provenía del cliente, que puede hablar inglés. La ruta de subtítulos en vivo solo reconocía etiquetas cortas en formato ISO, por lo que nombres como English o Spanish podían degradarse a detección heurística.

## Cambio
Se elimina la restricción de español en la transcripción durable y se solicita preservar el idioma original con detección automática entre inglés y español. Las etiquetas recibidas se normalizan desde nombres de idioma, códigos y variantes regionales BCP-47 antes de renderizar o persistir el segmento. Cada segmento durable conserva el idioma detectado. Se agregan pruebas unitarias y una prueba de enrutamiento para impedir que una regresión vuelva a fijar español.

## Motivo
Cubrir el requisito bilingüe original de la llamada y mantener la asignación visual ENGLISH/CLIENTE y ESPAÑOL/LEP incluso si el motor devuelve etiquetas de idioma distintas.

## Resultado esperado
La transcripción durable y el overlay efímero aceptan inglés y español sin imponer un idioma de entrada. La prueba automatizada demuestra que la configuración y los segmentos conservan ese contrato; aún hace falta comprobar calidad, latencia y continuidad en una llamada bilingüe real.

## Validación
Pendiente de CI hospedado y prueba operativa extremo a extremo. Este cambio no se declara liberado hasta comprobar ambos recorridos en el entorno real.
