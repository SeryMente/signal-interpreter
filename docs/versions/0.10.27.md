# Signal Interpreter 0.10.27 — Atajos de verificación congruentes y copia fiable

## Base

La versión 0.10.26 corrigió la atribución de hablantes para que la fuente de audio determine el carril CLIENTE/LEP y el idioma se conserve como metadato. Durante la revisión de usabilidad posterior se identificaron dos bordes en las acciones del overlay.

## Cambio

- Un `Ctrl+clic` sobre un teléfono o dirección abre la verificación prevista: búsqueda literal del teléfono o Google Maps para la dirección.
- Un `Ctrl+Mayús+clic` sobre texto común abre Linguee.
- Un `Ctrl+clic` sobre texto común ya no abre Linguee; el comportamiento corresponde exactamente al atajo comunicado en el encabezado. Clic simple sobre teléfonos/direcciones sigue copiando el valor reconocido.
- El manifiesto declara `clipboardWrite` para respaldar el fallback `document.execCommand("copy")` cuando la Clipboard API no puede completar la copia. Chromium recomienda ese permiso para extensiones que usan el comando de copia.
- Se añaden aserciones estáticas para proteger la semántica de atajos, el permiso de copia y la versión del manifiesto.

## Motivo

Los gestos de mouse deben ser previsibles y mutuamente distinguibles. Una búsqueda inesperada puede desviar al usuario durante una llamada y los datos críticos deben poder copiarse con un gesto directo. El permiso adicional limita la ambigüedad del fallback de copia, aunque Chrome puede mostrar una advertencia de modificación del portapapeles en la instalación/actualización.

## Validación

Los workflows de GitHub Actions deben pasar sobre el SHA de esta versión antes de integrarla. La validación automatizada cubre contratos y regresiones de código, no sustituye una prueba de copia en Chrome ni la validación funcional con una llamada real de Cloud Interpreter.

## Resultado esperado

- Clic en teléfono/dirección: copiar el texto detectado literalmente.
- Ctrl+clic en teléfono/dirección: abrir búsqueda de verificación.
- Ctrl+Mayús+clic sobre un término: abrir Linguee.
- Ctrl+clic sobre texto ordinario: no abrir una búsqueda accidental.

## Límites

El permiso `clipboardWrite` habilita la capacidad de copia usada por el fallback; no certifica por sí mismo el portapapeles en todos los contextos de Chrome. La comprobación final requiere recargar la extensión 0.10.27 y probar los gestos en el overlay real. La detección de números y direcciones sigue siendo heurística y no verifica que los datos reconocidos sean correctos.
