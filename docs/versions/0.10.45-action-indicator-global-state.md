# Signal Interpreter 0.10.45 — estado global del indicador

## Antes
Cada pestaña ajena a Cloud Interpreter recibía azul de forma incondicional. El estado rojo del perfil de Cloud Interpreter no se propagaba y los eventos de disponibilidad/readiness solo actualizaban el icono de la pestaña emisora.

## Cambio
- El indicador externo se deriva del estado de las pestañas de Cloud Interpreter.
- Azul (#3b82f6) solo cuando al menos una pestaña del perfil autorizado está verde: readiness exacta y reciente, Auto-Answer habilitado, guardia armada y disponibilidad online.
- Rojo cuando Cloud Interpreter está deshabilitado; gris cuando está offline; ámbar si no hay confirmación o no existe una pestaña Cloud Interpreter.
- Readiness, disponibilidad, configuración y cambios en signalPresenceGuard (armado/pausa desde popup), cierre/navegación de pestañas y toggle de Auto-Answer recalculan todos los indicadores.
- Con varias pestañas Cloud, un estado verde válido prevalece; sin verde se prioriza rojo, luego gris y después ámbar.

## Motivo
Evitar la contradicción visual rojo-en-Cloud / azul-fuera-de-Cloud.

## Resultado esperado
| Estado en Cloud Interpreter | Pestañas externas |
|---|---|
| Verde / activo | Azul |
| Rojo / deshabilitado | Rojo |
| Gris / offline | Gris |
| Ámbar / espera o sin evidencia | Ámbar |
