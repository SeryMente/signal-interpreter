# Signal Interpreter 0.10.24 — Overlay legible, desplazable y configurable

## Antes
La versión 0.10.23 priorizaba la compacidad: cuatro intervenciones, dos líneas visibles por intervención y un máximo de 210 px de alto. El usuario no podía revisar el diálogo anterior desde el overlay ni mover o redimensionar el panel. Algunos estados textuales del popup contenían secuencias UTF-8 mal interpretadas y el alcance del overlay no era configurable.

## Cambio
- Sustituir la tarjeta de cuatro filas por un historial vertical desplazable de hasta 800 intervenciones recientes, retenido en `chrome.storage.session` para sobrevivir a la suspensión del service worker, sin escribir el texto hablado en almacenamiento local duradero.
- Mantener la fusión de fragmentos parciales, la actualización incremental y el cálculo automático entre ocho posiciones que minimizan el solapamiento con controles interactivos.
- Permitir mover el panel arrastrando el encabezado, redimensionarlo desde la esquina inferior derecha y ajustar ambas operaciones mediante teclado; añadir «Auto» para recuperar el tamaño y la colocación inteligentes.
- Persistir solo la posición y el tamaño en la configuración local del perfil de Chrome.
- Añadir los alcances `source-only` (predeterminado) y `all-tabs`. El service worker valida la preferencia y distribuye actualizaciones de manera selectiva a las pestañas web.
- Conservar el historial tras finalizar una llamada y limpiarlo al iniciar una sesión nueva o cambiar el origen.
- Integrar el overlay en páginas web adicionales sin duplicar el content script principal de Cloud Interpreter.
- Mantener el adaptador de YouTube limitado al identificador `TshOFzKQfG8`.
- Corregir las cadenas mojibake encontradas en el popup y añadir aserciones de regresión para codificación y experiencia de uso.

## Motivo
La prioridad pasa de una tarjeta mínima a una herramienta legible y controlable. Durante una llamada, es necesario revisar turnos previos sin interrumpir la conversación, elegir si el panel sigue al origen o permanece visible en otras pestañas y moverlo cuando interfiere con un elemento de la página.

## Resultado
El panel proporciona historial navegable, posición y tamaño ajustables, preferencia de alcance y retorno a la colocación automática. El host conserva `pointer-events: none`; los controles del panel son interactivos. El historial se limita a 800 intervenciones y 1.500 caracteres por intervención, dentro del almacenamiento de sesión de Chrome.

## Validación y límites
La suite de GitHub Actions debe pasar antes de fusionar este cambio. No se afirma que el renderizado haya sido comprobado visualmente en una llamada bilingüe real: esa verificación requiere recargar la extensión en Chrome y comprobar el historial largo, el solapamiento con controles y el cambio de alcance durante una llamada real.
