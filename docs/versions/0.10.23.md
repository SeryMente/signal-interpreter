# Signal Interpreter 0.10.23 — Overlay compacto y no obstructivo

## Antes
El overlay ya evitaba capturar clics y puntuaba ocho posiciones contra los controles interactivos visibles de Cloud Interpreter. Sin embargo, una transcripción excepcionalmente larga podía expandir la tarjeta y tapar visualmente una parte excesiva de la llamada.

## Cambio
- Limitar la tarjeta a 210 px de altura con recorte visual seguro.
- Mostrar como máximo cuatro intervenciones recientes.
- Limitar cada intervención a dos líneas visibles, manteniendo el texto completo internamente para la fusión de parciales.
- Añadir aserciones de regresión al audit estático para estos límites y conservar la comprobación de `pointer-events:none`.
- Mantener la lectura nativa de Chrome como fuente prioritaria cuando Windows UI Automation expone la burbuja; usar el preview efímero existente solo cuando el texto nativo no está disponible o queda obsoleto.

## Motivo
Reducir el riesgo de que la interfaz auxiliar oculte el keypad numérico, mute u otros controles, especialmente ante cadenas largas o ruido de reconocimiento.

## Resultado
La presentación queda acotada sin añadir permisos, servicios residentes, dependencias ni nuevos controles. Los datos siguen actualizándose en el mismo Shadow DOM y el overlay conserva su comportamiento no interactivo.

## Límite técnico explícito
Al cerrar la burbuja nativa, Windows UI Automation puede dejar de exponer su árbol de texto aunque el interruptor de Live Caption permanezca encendido. En ese caso no se debe fingir que la transcripción nativa sigue accesible: el flujo existente cambia al preview efímero de baja latencia. La verificación final requiere una llamada real en la máquina de uso.
